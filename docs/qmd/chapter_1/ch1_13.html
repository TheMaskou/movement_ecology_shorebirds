Site use - hours (Fullerton case)

Published

2026-09-01

Why this station is treated differently

Fullerton Entrance carries a single directional Yagi antenna (6-elements). Unlike the small omni-directional antennas used across the rest of the Motus array in the Hunter estuary (see Motus Array Maintenance), and capable of tracking site use directly, Fullerton Entrance station is located strategically: it sits on the corridor between the main area (estuary covered by several omni antennas) and the biggest and main mudflat of the area (Fullerton Cove), which has no antenna coverage at all because of its terrain configuration. So, in order to track movement and site use over this big mudflat (Fullerton Cove, or also called Fullerton mudflat), we placed a station right at the entry (Fullerton Entrance), to detect in-and-out passages.

Therefore, a tag detection at Fullerton Entrance station is either:

  • fly-by, the bird briefly fly by (in front of) the antenna, probably traveling between the estuary (roost?) and Fullerton mudflat (foraging?)

  • site use - the bird is actually sitting by the antenna itself, either roosting or foraging, using the site.

Since we cannot detect birds directly on Fullerton mudflat, we use fly-by detections at Fullerton Entrance station and their direction (another station → Fullerton Entrance or another station → Fullerton Entrance) as an indirect proxy for mudflat use.

When is it a fly-by?

A very short visit (seconds to a couple of minutes) most likely reflects a bird flying by the antenna; while a longer visit likely reflects a bird actually using the site covered by antenna’s range coverage. We use the same mixture-model approach as for the detection-gap threshold (see Station usage - hours (OBP method)), but here fitted to visit durations at Fullerton Entrance only, to find a data-driven cut-off between “flyby” and “actual use”.

Fit a 2-component mixture model on log-transformed visit duration (component 1 = short/flyby, component 2 = long/actual use), and find the cut-point where the posterior probability of belonging to the “flyby” component drops below 0.5.

set.seed(123)

mix_fc <- normalmixEM(               # we assume normal distributions only
  log(fc_visits$duration_min + 1),   # +1 to avoid log(0), and log() used to compress/scale duration distributions and tails (i.e., lot of short vs few long)
  k = 2,                             # we assume two potential distribution (flyby and site use)
  maxit = 5000,                      # number of iteration to estimate what component each observation belogs to
  epsilon = 1e-08)                   # standard threshold value for estimation (convergence tolerance)
number of iterations= 21 
comp_order_fc <- order(mix_fc$mu)    # sort components -> comp_1 with smaller mean first (fly-by)

post_short    <- mix_fc$posterior[, comp_order_fc[1]] # extract first col of mix_fc$posterior, a matrix with one row per visit and one column per component, containing each visit's posterior probability of belonging to that component (rows sum to 1). So, post_short is a vector giving one value per visit of "probability this visit is a fly-by."

cut_df <- data.frame(duration_h = fc_visits$duration_h, p_short = post_short) %>%
  arrange(duration_h)

flyby_cutpoint_h <- cut_df$duration_h[which(cut_df$p_short < 0.5)[1]] # /!\ the value chosen here (0.5) finds the first duration in hour (smallest) where it has less than 50 % probability to be a fly-by /!\

Under 0.18 hours (~ 11 min), a detection at Fullerton Entrance is considered as a fly-by and above as a site use. So, let’s classify and visualise.

fc_visits <- fc_visits %>%
  mutate(visit_type = if_else(duration_h < flyby_cutpoint_h, "flyby", "actual_use"))

Fly-by direction

For flyby events specifically, we want to know whether the bird was heading to the mudflat (last seen leaving the roost area, i.e. detected at another station shortly before the flyby) or coming from the mudflat (detected at another station shortly after the flyby). To do so, we need to understand what is the right temporal window to consider for defining the “shortly after” or “shortly before”, and to rely on inference only when the detection into anothe Motus station is beyond this value.

Let’s start by splitting the data-set accordingly before to estimate the direction of a fly-by depending on the tide: toward the mudflat of Fullerton cove if the fly-by is detected during a falling tide, and inversly if detected during a rising tide.

flyby_visits <- fc_visits %>% filter(visit_type == "flyby")

all_visits_dt   <- as.data.table(visit_duration)
other_visits_dt <- all_visits_dt[recvDeployName != focal_station]
flyby_dt        <- as.data.table(flyby_visits)
flyby_dt <- flyby_dt %>%
  
  rowwise() %>%
  
  mutate(
    next_tide = list(
      tide_data %>%
        filter(tideDateTimeAus >= visitStart,
               tideDateTimeAus <= visitStart + lubridate::hours(10)) %>%
        slice_min(tideDateTimeAus, n = 1)), # takes the next tide peak from NSW forecast
    
    nearestNextDiel = next_tide$day_night[1],
    nearestNextTide = next_tide$high_low[1]) %>%
  
  ungroup() %>%
  select(-next_tide) %>%
  
  mutate(
    direction = case_when(
      nearestNextTide == "High" ~ "From mudflat (rising tide)",
      nearestNextTide == "Low"  ~ "To mudflat (falling tide)",
      TRUE ~ NA_character_ ))


barplot(table(flyby_dt$direction, useNA = "ifany"),
        main = "Inferred flyby direction based on next tide",
        ylab = "Count of flybys")

For each fly-by detected at Fullerton Entrance, we then look for a confirming detection at another Motus station: if the tide was rising, we check for the closest following detection after Fullerton Entrance; if the tide was falling, we check for the closest preceding detection before Fullerton Entrance.

flyby_dt <- flyby_dt %>%
  
  rowwise() %>%
  
  mutate(
    .band    = Band.ID,
    .start   = visitStart,
    .station = recvDeployName,
    
    other_visit = list(
      if (!is.na(direction) && direction == "From mudflat (rising tide)") {
        all_visits_dt %>%
          filter(Band.ID == .band,
                 recvDeployName != .station,
                 visitStart >= .start) %>%
          slice_min(visitStart, n = 1)
      } else if (!is.na(direction) && direction == "To mudflat (falling tide)") {
        all_visits_dt %>%
          filter(Band.ID == .band,
                 recvDeployName != .station,
                 visitStart <= .start) %>%
          slice_max(visitStart, n = 1)
      } else {
        all_visits_dt %>% filter(FALSE)
      }
    ),
    side_detection = other_visit$recvDeployName[1],
    delay = as.numeric(abs(difftime(.start, other_visit$visitStart[1], units = "mins")))
  ) %>%
  ungroup() %>%
  select(-other_visit, -.band, -.start, -.station)

We then look at the distribution of the delay between a detectiona at Fullerton entrance and another Motus station, in order to identify a temporal window we can use as a cut-off for concluding that “the bird flew continuously between the fly-by detection at Fullerton Entrance and the next detection at another Motus station” (or, in the reverse case, between a detection at another station and the fly-by at Fullerton entrance during a falling tide).

We first filter out any extreme tail in the data, then visualise the distribution to estimate how many underlying components it contains.

flyby_dt_trimmed  <- flyby_dt %>% 
  filter(flyby_dt$delay < 4000)

hist(flyby_dt_trimmed$delay,
     breaks = 50,
     main  = "Delay to (or period before) nearest next site detection",
     xlab  = "Delay (minutes)")

Visually, we can estimate that the overall temporal window for continuous flights between the Fullerton entrance and another Motus station is about 10 minutes. However, we can fit an N-mixture model to confirm this.

delay_vals <- na.omit(flyby_dt_trimmed$delay)
set.seed(1)  # EM is stochastic in its starting values
mix <- normalmixEM(delay_vals, 
                   k = 2)
plot(mix, which = 2)
# order components so mu1 < mu2 (short-delay vs long-delay cluster)
ord    <- order(mix$mu)
mu     <- mix$mu[ord]
sigma  <- mix$sigma[ord]
lambda <- mix$lambda[ord]

# find where the two weighted densities cross, between the two means
f <- function(x) lambda[1]*dnorm(x, mu[1], sigma[1]) - lambda[2]*dnorm(x, mu[2], sigma[2])
flyby_window_min <- uniroot(f, lower = mu[1], upper = mu[2])$root
flyby_window_min

With a statistically determined threshold, any delay between a detection at the Fullerton entrance and a another Motus station that is shorter than 10.7672842 ​ minutes will be treated as a verified flight direction for the bird. Beyond this value, a continuous flight is not considered realistic, and detections at other Motus stations cannot be trusted to infer the bird’s flight direction. See below for the distribution of these results.

Rate of use

For actual site use events, the duration a bird spent at Fullerton Entrance is simply duration_h of the visit itself.

For fly-bys there is no direct duration - instead we use the surrounding tide turning point as a proxy boundary for how long the bird likely remained on the mudflat:

  • To mudflat (falling tide) - from the moment the bird was detected (visitEnd) to the next tide turning point (i.e. the remainder of the current tide phase).
  • From mudflat (rising tide) - from the previous tide turning point back to the moment the bird was detected (visitStart) (i.e. how long the current tide phase had already run before the bird arrived for detection).
# Nearest tide turning point before / after a given timestamp
tide_times <- sort(tide_data$tideDateTimeAus)

next_tide_turn <- function(t) {
  cand <- tide_times[tide_times > t]
  if (length(cand) == 0) return(as.POSIXct(NA))
  min(cand)
}
prev_tide_turn <- function(t) {
  cand <- tide_times[tide_times < t]
  if (length(cand) == 0) return(as.POSIXct(NA))
  max(cand)
}

# Dominant tideCategory across a time window (hourly expansion, nearest-tide join)
tide_dt <- as.data.table(tide_data)[order(tideDateTimeAus), .(tideDateTimeAus, tideCategory)]

dominant_tide <- function(w_start, w_end) {
  if (is.na(w_start) || is.na(w_end) || w_end <= w_start) return(NA_character_)
  hrs    <- seq(floor_date(w_start, "hour"), floor_date(w_end, "hour"), by = "hour")
  hrs_dt <- data.table(hour_dt = hrs)
  matched <- tide_dt[hrs_dt, on = .(tideDateTimeAus = hour_dt), roll = "nearest"]
  names(sort(table(matched$tideCategory), decreasing = TRUE))[1]
}

Build the per-visit duration/tide table.

plot_data <- fc_classified %>% 
  mutate(direction = replace_na(direction, "Actual site use")) %>% ## Be careful and know your data here
  
  filter(direction %in% c("Actual site use", 
                          "To mudflat (falling tide)",
                          "From mudflat (rising tide)")) %>%
  rowwise() %>%
  mutate(
    category = if_else(direction == "Actual site use",
                       "Fullerton entrance", "Fullerton mudflat"),
    win_start = case_when(
      direction == "Actual site use"                    ~ visitStart,
      direction == "To mudflat (falling tide)"    ~ visitEnd,
      direction == "From mudflat (rising tide)"   ~ prev_tide_turn(visitStart)),
    win_end = case_when(
      direction == "Actual site use"                    ~ visitEnd,
      direction == "To mudflat (falling tide)"    ~ next_tide_turn(visitEnd),
      direction == "From mudflat (rising tide)"   ~ visitStart),
    duration_h_final = as.numeric(difftime(win_end, win_start, units = "hours")),
    tideCategory_dom  = dominant_tide(win_start, win_end),
    tideDiel = if_else(grepl("Diurnal", tideCategory_dom), "Diurnal", "Nocturnal")
  ) %>%
  ungroup() %>%
  filter(!is.na(duration_h_final), duration_h_final > 0)

Because “Fullerton mudflat” is an inferred location rather than a real receiver, both categories are expressed as a rate against the same denominator: the hours Fullerton Entrance was available (station on + bird tagged and alive), per bird and per diel period. This comes from available_bird_recv_time, computed in the previous chapter.

# Available hours at Fullerton Entrance, per bird / species / diel period
available_fc <- available_bird_recv_time %>%
  filter(recvDeployName == "Fullerton Entrance") %>%
  group_by(Band.ID, speciesEN, tideDiel) %>%
  summarise(available_h = sum(duration_h), .groups = "drop")

# Used hours per bird / category / diel period, then compute rate of use (%)
plot_summary <- plot_data %>%
  group_by(Band.ID, speciesEN, category, tideDiel) %>%
  summarise(used_h = sum(duration_h_final), .groups = "drop") %>%
  left_join(available_fc, by = c("Band.ID", "speciesEN", "tideDiel")) %>%
  mutate(rate_use = (used_h / available_h) * 100,
         rate_use = pmin(rate_use, 100))  # cap: a few cases exceed 100% (see note below)

Note: a small number of birds show rate_use above 100%, since mudflat duration is inferred from tide turning points rather than directly observed, and can occasionally exceed the bird’s directly-available Fullerton Entrance time. These values are capped at 100% rather than excluded.
