Site use adjusted for detection gap threshold

Detection threshold

To define independent observations, we needed a time gap that separates a bird leaving a site from just briefly dropping out of antenna range (e.g., by turning away or moving behind vegetation). Short gaps likely mean the bird is still present; long gaps likely mean it has left. We analysed the distribution of time gaps between successive detection runs of the same bird at the same station, and across all individuals, and used this to choose a cut-off separating “same visit” from “new visit”. A three-component mixture model (MIXTOOLS 2.0.0.1) was fitted to the gap durations, distinguishing short gaps (same visit) from medium/long gaps (new visit). Gaps were truncated to 5 min – 30 hours to remove noise from very short or very long outliers, and each gap was classified by whichever distribution best matched it.

1. Build run-level summary (one row per run) from hits. A “run” is already identified by runID in data_all (see Motus documentation - Chapter 3). We need the start/end time of each run, per individual and per station.

runs <- data_all %>%
  group_by(speciesEN, Band.ID, recvDeployName, runID) %>%
  summarise(
    runStart = min(timeAus, na.rm = TRUE),
    runEnd   = max(timeAus, na.rm = TRUE),
    n_detect = n(), 
    .groups = "drop")

2. Compute gaps between successive runs of the same individual at the same antenna/site.

gaps <- runs %>%
  arrange(Band.ID, recvDeployName, runStart) %>%
  group_by(Band.ID, recvDeployName) %>%
  mutate(
    prevRunEnd = dplyr::lag(runEnd),
    gapHours   = round(as.numeric(difftime(runStart, prevRunEnd, units = "hours")), 2)) %>%
  ungroup() %>%
  filter(!is.na(gapHours)) %>%
  filter(gapHours > 0) # we are not dealing with overlaps yet (simultaneous detection of the same tag from two or more antenna)

3. Truncate gaps (hours) for mixture model fitting.

::: blockquote-yellow NOTE: Below are values you should choose based on your own data and on the ecological plausibility of your system. :::

4. Fit a 3-component normal mixture model. Now we have visually explored how data is distributed to select a gap threshold value, we might use statistical model to assess this value more systematical and based on the data only, besides visual selection accounting for ecologically plausibility.

gap_trunc <- gaps %>%
  filter(gapHours > 0.3,     # ~5 minutes                   
         gapHours < 30) %>%  # 30 hours
  pull(gapHours)

set.seed(123)  # for reproducibility of EM starting values

mix_model <- normalmixEM(
  log(gap_trunc +1),         # +1 to avoid log(0), and log() used to compress/scale duration distributions and tails (i.e., lot of short vs few long)
  k = 3,
  maxit = 5000,
  epsilon = 1e-08)

6. Find the threshold value, the cut-point: the gap value where classification switches from “Non-independent” to an “Independent” class (i.e. where posterior prob of the non-independent component drops below 0.5 as gap duration increases). We will first classify each gap to the component with highest posterior probability, and order components by their mean, so component 1 = shortest-gap (non-independent), 2 = medium, 3 = long (independent).

Define used time (hours)

Now, we decide to merge into one and unique continuous detection, all the tags (birds) detected per a same antenna, including gaps under a duration of 1 (one) hour. Although the model is highlighting a value of 1.45, we decided to remain conservative.

Once detection data summarised as described above, we can see, overall, how long birds stay around one Motus station - see plot below.

visit_duration <- runs %>%
  arrange(Band.ID, recvDeployName, runStart) %>%
  group_by(Band.ID, recvDeployName) %>%
  mutate(
    gapHours = round(as.numeric(runStart - dplyr::lag(runEnd))  / 3600, 2),
    new_visit = is.na(gapHours) | gapHours >= 1,                 # <-- HERE IS THE THRESHOLD VALUE TO SET A "NEW VISIT" (TRUE when gapHours >= 1) 
    visitID = cumsum(new_visit)) %>%
  group_by(Band.ID, speciesEN, recvDeployName, visitID) %>%
  summarise(
    visitStart = min(runStart),
    visitEnd   = max(runEnd),
    n_detect   = sum(n_detect),                                  # total hits/detection across merged runs
    n_runs     = n(),                                            # how many runs got merged into this visit
    .groups = "drop") %>%
  
  mutate(duration_h = round(as.numeric(visitEnd - visitStart) / 3600, 2))    # visit duration in hours


ggplot(visit_duration %>%
         filter(duration_h < 20),
       aes(x = duration_h, y = after_stat(count))) +
  geom_histogram(binwidth = 0.5, 
                 fill = "grey30", 
                 color = "white") +
  scale_x_continuous(breaks = seq(0, 20, 1)) + # 1h
  labs(x = "Visit Duration (hours)", y = "Count (n)") +
  theme_minimal(base_size = 13) +
  theme(panel.grid.minor = element_blank())

*Note Newcastle NSW tides are turning ~6h cycles between high/low, and our birds seem to mostly visits any site less than 3 hours. An early descriptive sign of site use very tide dependent, as they would stay about 3 hours in the same area, around the highest/lowest point of the tide line, before to leave site, as the tide might be rising or receiving.*

To avoid inflating site use duration estimates with the very few individuals showing more than 25 hours of continuous presence in the same area, we excluded these cases. Such extended duration likely reflect a dropped tag rather than genuine site fidelity. Verifying each case individually would be time-consuming, so we treat this as a working assumption for now; should this pattern become more frequent in future data, it would warrant closer investigation.

visit_duration <- visit_duration %>%
         filter(duration_h < 25)

It remains to attribute at each visit period a tide category. We expand each visit into hourly bins spanning visitStart to visitEnd (visit_duration itself is untouched). Then, we compute exact overlap (in hours) between each hourly bin and the actual visit window.

visit_hours <- visit_duration %>%
  rowwise() %>%
  mutate(hour_dt = list(seq(from = floor_date(visitStart, "hour"),
                             to   = floor_date(visitEnd, "hour"),
                             by   = "hour"))) %>%
  unnest(cols = c(hour_dt)) %>%
  ungroup()

visit_hours <- visit_hours %>%
  mutate(
    bin_start     = hour_dt,
    bin_end       = hour_dt + hours(1),
    overlap_start = pmax(visitStart, bin_start),
    overlap_end   = pmin(visitEnd, bin_end),
    overlap_h     = as.numeric(difftime(overlap_end, overlap_start, units = "hours"))
  ) %>%
  filter(overlap_h > 0)   # drops bins with no actual overlap

# Attach nearest tide category to each hourly bin
tide_dt <- as.data.table(tide_data)[, .(tideDateTimeAus, tideCategory)]
setkey(tide_dt, tideDateTimeAus)

vh_dt <- as.data.table(visit_hours)
setkey(vh_dt, hour_dt)

visit_hours_tide <- tide_dt[vh_dt, on = .(tideDateTimeAus = hour_dt), roll = "nearest"]
setnames(visit_hours_tide, "tideDateTimeAus", "hour_dt")

Let’s finalise the table giving data for detection relative to the trio bird-station-tide.

used_bird_recv_time <- visit_hours_tide %>%
  mutate(tideDiel = if_else(grepl("Diurnal", tideCategory), "Diurnal", "Nocturnal"),
         tideHighLow = if_else(grepl("High", tideCategory), "High", "Low")) %>%
  group_by(Band.ID, speciesEN, recvDeployName, tideCategory, tideDiel, tideHighLow) %>%
  summarise(duration_h = sum(overlap_h), .groups = "drop")

Define available time (hours)

Now used time addressed, we need to define for each individual (birds) and across each Motus stations, what was the amount of time available for the four tide categories.

Available time for each Motus stations is accessed with activity table: each row is a dated record of noise or a tag detected - see Survey effort > Activity table.

We need to extract the temporal coverage of each station, starting from deployment date to the last recorded activity (noise or detection).

# Sort the terminated serno (if terminated, ie. one box removed from one antenna site, a date comes along)

We now have the complete temporal coverage, expanded in hours and for each Motus station so it matches with our used time dataset.

However, due to some temporary failures or maintenance (see Survey effort > Operational periods), the actual period a station was operational may be different than the complete temporal coverage. So, we must determine when a station was not operational and substrate these off-hours to the complete temporal coverage.


# Distinguish station from mixed recv + Giving operational variable (= TRUE when existing values from act table)
recv_hours <- recv_hours %>%

Temporal coverage for each station is now reduced to its operational periods. We now assign each bird its own available time period, spanning from its tagging date to its last Motus detection, and expanded to hourly resolution too.


# Get the monitored period of each bird
period_sp <- data_all  %>%
  group_by(Band.ID) %>%
  reframe(DateAUS.Trap = dplyr::first(DateAUS.Trap), 
          last_dateAus = max(timeAus),
          speciesEN = dplyr::first(speciesEN)) %>%
  unique()

# Expand one row per hours to each individual across its whole period (this is the available time)
bird_hours <- period_sp %>%
  group_by(Band.ID) %>%
  rowwise() %>%
  mutate(hour_dt = list(seq(from = as.POSIXct(ymd(DateAUS.Trap), tz = "UTC"),
                            to = as.POSIXct(last_dateAus, tz = "UTC"),
                            by = "hour"))) %>%
  unnest(cols = c(hour_dt)) %>%
  ungroup() 

# Duplicate in as many list as many stations
recv_names <- unique(valid_station_hours_tide$recvDeployName)
bird_data_list <- setNames(vector("list", length(recv_names)), recv_names)

for(name in recv_names) {
  valid_hours_recv <- valid_station_hours_tide %>%
    filter(recvDeployName == name) %>%
    pull(hour_dt)
  
  valid_hours_bird_recv <- bird_hours %>%
    filter(hour_dt %in% valid_hours_recv)
  
  valid_hours_bird_recv$name <- name
  bird_data_list[[name]] <- valid_hours_bird_recv
}

# # FINALISE AVAILABLE TIME 
available_bird_recv_time <- bind_rows(bird_data_list) %>%
  mutate(hour_dt = force_tz(hour_dt, "Australia/Sydney")) %>%
  filter(if_all(everything(), ~ !is.na(.))) %>%
  rename(recvDeployName = name) %>%
  left_join(valid_station_hours_tide, by = c("recvDeployName", "hour_dt")) %>%
  filter(!is.na(tideCategory)) %>%    # bird-hours the station wasn't actually ON for get dropped here
  group_by(Band.ID, speciesEN, recvDeployName, tideCategory) %>%
  summarise(duration_h = n(), .groups = "drop") %>%
  mutate(tideDiel = if_else(grepl("Diurnal", tideCategory), "Diurnal", "Nocturnal"),
         tideHighLow = if_else(grepl("High", tideCategory), "High", "Low")) %>%
  select(Band.ID, speciesEN, recvDeployName, tideCategory, tideDiel, tideHighLow, duration_h)

The available time is now defined for each bird across each Motus station, taking into account the periods where stations where ON only. In the data, the available periods are expanded in hours and the tide condition is associated. While most of the couple station listening-bird tagged are potentially detectable between 0 and 1000 hours; note two small peaks around 2700 and 4000 hours of detectability potential as it might be relative to the oldest couple ON.

Define rate of Use (%)

Now that the used and available time have been determined for each individual and for each Motus station, we can relate these two elements together with the Usage rate (or rate of use).

\[ \text{Usage rate} = \frac{\text{Time used}}{\text{Time available}} \times 100 \quad \textit{across stations and species} \]

use_rate_plot <- used_bird_recv_time %>%
  select(-tideDiel, -tideHighLow) %>%   # drop here, keep the copy from available_bird_recv_time
  rename(used_h = duration_h) %>%
  
  left_join(available_bird_recv_time %>%
      rename(available_h = duration_h),   
    by = c("Band.ID", "speciesEN", "recvDeployName", "tideCategory")) %>%
  
  mutate(rate_use = (used_h / available_h) * 100) %>%
  select(Band.ID, speciesEN, recvDeployName, tideCategory, 
         tideDiel, tideHighLow, used_h, available_h, rate_use)

Note: A very few cases (n = 2 / 387) where the time used was over the time available has been re-allocated the value 100%. Reasons might be the tag fell off within range of the antenna. Due to the negligible number of such cases, we have not further investigated. In average, the difference of time between available and used is 1.47 hours (32.925 % of rate of use difference).

use_rate_plot <- use_rate_plot %>%
  mutate(rate_use = ifelse(rate_use > 100, 100, rate_use))

Note: We filtered out Masked Lapwing from the analysis, since they have too few data.
We also filter out Fullerton Entrance station as it needs to be worked separately (see Site use - hours (Fullerton case))

Beta | Statistical analysis (GLM)

See exploratory analysis

Instead of simple “the boxplots look different” we statistically analyse with GLM the data to estimate tidal and circadian cycles effects per species, correctly weighted and accounting for the fact that a same bird may appears many times.

Additive model (direction ~ tide * species + diel * species)

# ============================================================================
# STATISTICAL MODEL OF SITE-USE RATE
# Question: does rate of use (used_h / available_h) differ by species,
# depending on tide state (High/Low) and diel period (Diurnal/Nocturnal)?
# ============================================================================

# --- WHY THIS MODEL AND NOT A BOXPLOT/T-TEST -------------------------------
# rate_use is a PROPORTION (used_h / available_h) with very unequal
# denominators: some bird x station x condition combos have available_h = 3h,
# others have available_h = 2000h. A boxplot / Wilcoxon test on rate_use
# treats a 100% rate based on 3h exactly the same as a 100% rate based on
# 500h - which is statistically wrong. A binomial-family model uses
# available_h as the number of "trials" per row, so noisy/low-effort
# estimates are automatically down-weighted relative to well-sampled ones.
# We also add Band.ID as a random effect because the same bird contributes
# many rows (non-independence across stations/conditions for one individual).

library(dplyr)
library(ggplot2)
library(glmmTMB)   # mixed models with beta-binomial family (handles proportion data + overdispersion)
library(DHARMa)    # residual diagnostics for GLMM(s)
library(emmeans)   # marginal means & pairwise post-hoc comparisons, back-transformed to % scale
library(car)       # Anova() omnibus tests
library(patchwork) # combine plots

# ==== 1. Prepare data ========================================================
# betabinomial() wants integer-like "successes" and "trials", so we convert
# hours to minutes and round. This just gives the model finer resolution
# than whole hours - it does NOT change what used_h/available_h represent.
model_data <- figure_plot %>%
  mutate(
    used_min      = round(used_h * 60),
    available_min = round(available_h * 60)
  ) %>%
  filter(available_min > 0,                  # can't divide by zero exposure
         used_min <= available_min) %>%       # safety check, should already be true
  droplevels()                                # drop unused factor levels (e.g. Masked Lapwing already filtered)

# ==== 2. Fit the model =======================================================
# Fixed effects: speciesEN interacted separately with tideDiel and with
# tideHighLow, so we can ask "does the day/night effect differ by species?"
# and "does the tide-height effect differ by species?" without blowing up
# the model with a full 3-way interaction (keeps it simple, as requested).
# Random effects: (1|Band.ID) accounts for repeated measures per bird;
# (1|recvDeployName) accounts for station-to-station baseline differences
# without spending a fixed-effect parameter per station (partial pooling -
# more robust than a fixed effect when some stations have very few birds).
m_site_use <- glmmTMB(
  cbind(used_min, available_min - used_min) ~
    speciesEN * tideDiel +
    speciesEN * tideHighLow +
    (1 | Band.ID) +
    (1 | recvDeployName),
  family = betabinomial(),    # like binomial, but allows extra-binomial variance (very common in ecological count/proportion data)
  data   = model_data
)

summary(m_site_use)

# ==== 3. Check the model actually fits reasonably ===========================
# DHARMa simulates data from the fitted model and compares it to your real
# data: if the model is adequate, the simulated residuals should look
# uniform. This is a quick, honest sanity check before trusting any p-value.
sim_res <- simulateResiduals(m_site_use, n = 500)
plot(sim_res)                     # QQ-plot + residual-vs-predicted plot
testDispersion(sim_res)           # formal test: is there still over/under-dispersion left?
# If the dispersion test or QQ-plot looks bad, the most common simple fixes are:
#   - drop the recvDeployName random effect if it's estimated as ~0 (singular fit warning)
#   - simplify to speciesEN + tideDiel + tideHighLow (no interactions) if you have
#     convergence warnings, then only add interactions back one at a time.

# ==== 4. Omnibus test: does each term matter overall? =======================
# Answers "does species matter at all", "does tideDiel matter at all", etc.,
# collapsing across factor levels - useful before diving into pairwise
# comparisons below.
Anova(m_site_use, type = "II")

# ==== 5. Pairwise comparisons: the actual biological question ===============
# (a) For each species, is Diurnal use different from Nocturnal use?
emm_diel <- emmeans(m_site_use, ~ tideDiel | speciesEN, type = "response")
diel_contrasts <- as.data.frame(pairs(emm_diel))   # keep as object: reused for stars below
print(diel_contrasts)

# (b) For each species, is High-tide use different from Low-tide use?
emm_tide <- emmeans(m_site_use, ~ tideHighLow | speciesEN, type = "response")
tide_contrasts <- as.data.frame(pairs(emm_tide))   # keep as object: reused for stars below
print(tide_contrasts)

# (c) Optional: are species different from each other overall (within a given
#     diel/tide condition)? Useful if you want a compact "who uses the array
#     most" ranking.
emm_species <- emmeans(m_site_use, ~ speciesEN, type = "response")
pairs(emm_species)

# --- helper: convert a p-value to conventional significance stars ----------
p_to_stars <- function(p) {
  dplyr::case_when(
    p < 0.001 ~ "***",
    p < 0.01  ~ "**",
    p < 0.05  ~ "*",
    TRUE      ~ "ns"      # "not significant"
  )
}

# --- helper: emmeans calls the back-transformed estimate column "prob" for
# binomial/beta-binomial models, and "response" for Gaussian-family models.
# This makes downstream code robust to either, so you don't need to remember
# which one applies for a given model family.
standardise_response_col <- function(df) {
  if ("prob" %in% names(df))          df <- df %>% rename(response = prob)
  else if (!"response" %in% names(df)) stop("No back-transformed estimate column found - check names(df).")
  df
}

Mixte model (direction ~ tide * diel * species)

# ============================================================================
# THREE-WAY INTERACTION MODEL
# Question: does the tide-height effect on rate of use depend on BOTH
# species AND diel period simultaneously? i.e. for each species, do we get
# four genuinely different estimates - Low Night, Low Day, High Night,
# High Day - or do some of these collapse into "not significantly different"?
# ============================================================================

# --- WHY THIS IS A BIGGER ASK THAN THE TWO SEPARATE TWO-WAY MODELS ----------
# speciesEN * tideDiel * tideHighLow estimates a separate mean for every
# species x diel x tide combination (4 conditions per species). This needs
# enough data in EVERY one of those cells to be trustworthy; some species or
# stations you've already seen are thin (n=1-2 birds), so expect wider CIs,
# some "ns" results, and possibly convergence warnings for the rarer species.
# This is the necessary trade-off for asking a more specific question.

library(conflicted)   # makes function-masking conflicts (e.g. select()) fail loudly instead of silently
library(dplyr)
library(ggplot2)
library(glmmTMB)
library(DHARMa)
library(emmeans)
library(car)
library(multcomp)     # for cld() - compact letter display of pairwise significance; also loads MASS,
                       # which is what silently masked dplyr::select() before - now handled below

# --- Lock in which version of commonly-masked functions to use. Run this
# once, right after all libraries are loaded, so it doesn't matter what
# order packages were loaded in, or what gets loaded later in the session.
conflicts_prefer(dplyr::select)
conflicts_prefer(dplyr::filter)

# ==== 1. Prepare data =========================================================
model_data <- figure_plot %>%
  mutate(
    used_min      = round(used_h * 60),
    available_min = round(available_h * 60)
  ) %>%
  filter(available_min > 0,                  # can't divide by zero exposure
         used_min <= available_min) %>%       # safety check, should already be true
  droplevels()                                # drop unused factor levels (e.g. Masked Lapwing already filtered)

# ==== 2. Fit the 3-way interaction model ======================================
# Fixed effect: full three-way interaction speciesEN * tideDiel * tideHighLow.
# Random effects unchanged: Band.ID for repeated measures per bird,
# recvDeployName for station-level baseline differences.
m_site_use_3way <- glmmTMB(
  cbind(used_min, available_min - used_min) ~
    speciesEN * tideDiel * tideHighLow +
    (1 | Band.ID) +
    (1 | recvDeployName),
  family = betabinomial(),
  data   = model_data
)

summary(m_site_use_3way)

# ==== 3. Model fit check =======================================================
sim_res_3way <- simulateResiduals(m_site_use_3way, n = 500)
plot(sim_res_3way)
testDispersion(sim_res_3way)
# If this throws convergence warnings (likely, given thin cells for some
# species), the simplest fallback is the two separate two-way models -
# that's the data telling you it can't support this many parameters yet,
# not a coding error.

# ==== 4. Omnibus test: is the 3-way interaction itself significant? ==========
# The key new test the two separate two-way models couldn't ask: does the
# tide-height effect change shape between day and night, and does THAT
# pattern differ by species? Look at the speciesEN:tideDiel:tideHighLow row.
Anova(m_site_use_3way, type = "II")
# If that row is NOT significant, the simpler two-way models remain the
# better-supported choice - the full 3-way term isn't needed.

# ==== 5. Pairwise comparisons across all 4 conditions per species ============
# For each species: 4 diel x tide combinations, compared pairwise
# (6 comparisons per species).
emm_3way <- emmeans(m_site_use_3way, ~ tideDiel * tideHighLow | speciesEN, type = "response")
contrasts_3way <- as.data.frame(pairs(emm_3way))
print(contrasts_3way)

# --- Compact Letter Display (cld): with 4 groups per species, individual
# stars per pair get cluttered fast. cld assigns a letter to each of the 4
# conditions per species; conditions sharing NO letter are significantly
# different, conditions sharing a letter are not. Standard way to summarise
# >2-group comparisons in one readable tag.
cld_3way <- cld(emm_3way, Letters = letters, adjust = "tukey") %>%
  as.data.frame()

# ==== 6. Plot: one panel per species, FOUR estimates per panel ===============
# (Low Night, Low Day, High Night, High Day) on a single x-axis

# --- helper: emmeans calls the back-transformed estimate column "prob" for
# binomial/beta-binomial models. Standardise so downstream code doesn't
# need to remember which name applies.
standardise_response_col <- function(df) {
  if ("prob" %in% names(df))          df <- df %>% rename(response = prob)
  else if (!"response" %in% names(df)) stop("No back-transformed estimate column found - check names(df).")
  df
}

# --- helper: collapse tideDiel + tideHighLow into one readable 4-level factor
combine_condition <- function(df) {
  df %>%
    mutate(
      condition = case_when(
        tideHighLow == "Low"  & tideDiel == "Nocturnal" ~ "Low Night",
        tideHighLow == "Low"  & tideDiel == "Diurnal"   ~ "Low Day",
        tideHighLow == "High" & tideDiel == "Nocturnal" ~ "High Night",
        tideHighLow == "High" & tideDiel == "Diurnal"   ~ "High Day"
      ),
      # fix the order left-to-right so it reads logically rather than alphabetically
      condition = factor(condition, levels = c("Low Night", "Low Day", "High Night", "High Day"))
    )
}

# --- 6a. Build the plotting data: estimates + CIs, with the 4-level condition

# --- 6d. Plot: ONE x-axis with all 4 conditions, one panel per species

       caption = "Letters shared between conditions = no significant difference; letters not shared = significant difference\n (p < 0.05, Tukey-adjusted).") +

        axis.text.x = element_text(angle = 45, hjust = 1),

Complete model (direction ~ tide * diel * species * station)

# ============================================================================
# FOUR-WAY MODEL: species x station x tide x diel
# Question: for each species, does site-use rate differ by station AND by
# tide/diel condition simultaneously?
# ============================================================================

# --- IMPORTANT CAVEAT --------------------------------------------------------
# This is a much larger model than the 3-way one. Many species only visit a
# handful of stations, and several species-station cells have very few birds
# (n=1-2, as seen in the earlier summary tables). Expect:
#   - wide confidence intervals for thin cells
#   - possible convergence warnings
#   - some panels essentially uninformative (huge CIs, all "a")
# This is the model correctly reflecting real data limits, not a bug.
# If it doesn't converge, the documented fallback is at the bottom.

library(conflicted)
library(dplyr)
library(ggplot2)
library(glmmTMB)
library(DHARMa)
library(emmeans)
library(car)
library(multcomp)

conflicts_prefer(dplyr::select)
conflicts_prefer(dplyr::filter)

# ==== 1. Prepare data =========================================================
model_data <- figure_plot %>%
  mutate(
    used_min      = round(used_h * 60),
    available_min = round(available_h * 60)
  ) %>%
  filter(available_min > 0,
         used_min <= available_min) %>%
  droplevels()

# ==== 2. Fit the model =========================================================
# Fixed effect: full 4-way interaction speciesEN * recvDeployName * tideDiel * tideHighLow.
# Random effect: (1|Band.ID) only - recvDeployName is now a FIXED term (it's
# part of the interaction we want estimates for), so it's no longer also a
# random effect (that would double-count it).
m_site_use_4way <- glmmTMB(
  cbind(used_min, available_min - used_min) ~
    speciesEN * recvDeployName * tideDiel * tideHighLow +
    (1 | Band.ID),
  family = betabinomial(),
  data   = model_data
)

summary(m_site_use_4way)

# --- FALLBACK if the above fails to converge or throws a rank-deficiency
# warning (very possible given the sparsity noted above): drop the full
# 4-way interaction down to pairwise interactions only, which is much more
# parsimonious and usually converges fine, while still letting station
# effects vary by species and by tide/diel:
#
# m_site_use_4way <- glmmTMB(
#   cbind(used_min, available_min - used_min) ~
#     speciesEN * recvDeployName +
#     speciesEN * tideDiel + speciesEN * tideHighLow +
#     recvDeployName * tideDiel + recvDeployName * tideHighLow +
#     (1 | Band.ID),
#   family = betabinomial(),
#   data   = model_data
# )

# ==== 3. Model fit check ========================================================
sim_res_4way <- simulateResiduals(m_site_use_4way, n = 500)
plot(sim_res_4way)
testDispersion(sim_res_4way)
# ==== 4. Omnibus test ============================================================
Anova(m_site_use_4way, type = "II")
# Look at the speciesEN:recvDeployName:tideDiel:tideHighLow row specifically.
# If it (or lower-order terms) aren't significant, the simpler 3-way model
# from before remains the better-supported, more honest choice.

# ==== 5. Get estimates - RESTRICTED TO COMBINATIONS THAT ACTUALLY EXIST ========
# This step is critical: emmeans by default will produce an estimate for
# EVERY theoretical species x station x tide x diel combination, including
# ones with zero real birds (e.g. a species that never visited that station).
# Those would be pure model extrapolation - not real information. We compute
# the full grid, then keep only rows matching combinations actually present
# in model_data.
emm_4way <- emmeans(m_site_use_4way,
                     ~ tideDiel * tideHighLow | speciesEN * recvDeployName,
                     type = "response")

observed_combos <- model_data %>%
  distinct(speciesEN, recvDeployName, tideDiel, tideHighLow)

emm_4way_df <- as.data.frame(emm_4way) %>%
  inner_join(observed_combos, by = c("speciesEN", "recvDeployName", "tideDiel", "tideHighLow"))

nrow(as.data.frame(emm_4way))   # theoretical grid size
nrow(emm_4way_df)               # actual, data-backed grid size - expect this much smaller

# ==== 6. Pairwise comparisons + compact letter display, per species x station ===
# Same logic as before: for each species x station panel, compare the 4
# tide/diel conditions pairwise, letters show which pairs are/aren't
# significantly different. Restricted to observed combos only, same as above.
contrasts_4way <- as.data.frame(pairs(emm_4way)) %>%
  semi_join(observed_combos, by = c("speciesEN", "recvDeployName"))
print(contrasts_4way)

cld_4way <- cld(emm_4way, Letters = letters, adjust = "tukey") %>%
  as.data.frame() %>%
  inner_join(observed_combos, by = c("speciesEN", "recvDeployName", "tideDiel", "tideHighLow"))

standardise_response_col <- function(df) {

# --- helper: build ONE species' plot, faceted by station -------------------
make_species_plot <- function(data, sp) {
  d <- data %>% filter(speciesEN == sp) %>% droplevels()

  ggplot(d, aes(x = condition, y = response * 100,
                ymin = asymp.LCL * 100, ymax = asymp.UCL * 100)) +
    geom_pointrange(size = 0.6, color = "#6CA0DC") +
    geom_text(aes(label = trimws(.group), y = asymp.UCL * 100 + 4),
              size = 3.2, fontface = "bold", color = "#2C3E50") +
    facet_wrap(~ recvDeployName) +
    coord_cartesian(ylim = c(0, 100)) +                   # cap the y-axis at 0-100%
    labs(x = NULL, y = "Model-estimated rate of use (%) [95% CI]",
         title = paste("Modelled site-use rate -", sp),
         subtitle = "Beta-binomial GLMM | letters = Tukey-adjusted compact letter display",
         caption = "Letters shared between conditions = no significant difference; letters not shared = significant difference (p < 0.05, Tukey-adjusted).\nOnly station x condition combinations present in the data are shown.") +
    theme_minimal(base_size = 12) +
    theme(strip.text = element_text(face = "bold"),
          axis.text.x = element_text(angle = 45, hjust = 1),
          plot.caption = element_text(hjust = 0, size = 8, color = "grey30", face = "italic"))
}
