Entropy, Eveness & Composition

Published

2026-10-12

Individual shorebirds vary a lot in how they use their sites in the estuary, so we want to quantify how much birds of the same species differ in this site use, and whether it might varies with tide.

There are two questions:

  1. Do birds of the same species use sites differently?

  2. If so, do they use different sites (private sites), or the same sites in different proportions (unequal use of shared sites)?

A few metrics will help us answering these questions, and below is a conceptual diagram in which metric to employ depending the question. Most of the analysis is derivative of the work of Balsega (2009, 2012 & 2013))

Time budget per site

We use overlap_h: the duration (hours) each bird was confirmed present at each site in each hourly tide-bin. Summing overlap_h per bird x site gives a duration-based “time budget” to assess the question “how much does this bird rely on this site”.

Here, we can already see that for some species, most of individuals use sites in a different manner within the estuary, and for other species, most individuals use site in a similar manner.

However, we need to build some metrics capable to inform the degree of this dissimilarity (or similarity) within site use between individuals of a same species.

And going deeper, we ask whether birds (1) use their sites differently, and if they do (2) whether they use different sites, or the same sites but dis similarly.

Metrics

Definition

We need to first manually build function to compute Jensen-Shannon Divergence metric (JSD), and store results in a matrix. Then we can use betapart package (Balsega et Orme - 2012) to extract Jaccard and Bray-Curtis metrics.

# Jensen-Shannon Divergence (JSD) function definition
calculate_jsd <- function(p, q) {
  eps <- 1e-10
  p <- (p + eps) / sum(p + eps)
  q <- (q + eps) / sum(q + eps)
  m <- (p + q) / 2
  0.5 * sum(p * log2(p / m)) + 0.5 * sum(q * log2(q / m))
}

# Pairwise divergence individuals (rows, named by Band.ID) x sites (cols), rows sum to 100
compute_divergence <- function(prop_mat) {

  if (nrow(prop_mat) < 2) return(NULL)   # need at least 2 birds to compare

  pa_mat <- (prop_mat > 0) * 1           # presence/absence version, for Jaccard

  # Use Balsega's (2013) package
  jac  <- betapart::beta.pair(as.data.frame(pa_mat),  index.family = "jaccard")     # Incidence-based pair-wise dissimilarities
  bray <- betapart::beta.pair.abund(as.data.frame(prop_mat), index.family = "bray") # Abundance-based pair-wise dissimilarities

  ids <- rownames(prop_mat)         
  pr  <- combn(nrow(prop_mat), 2)   # same pair order as a `dist` object's internal storage

  jsd_vals <- apply(pr, 2, function(ix) calculate_jsd(prop_mat[ix[1], ], prop_mat[ix[2], ]))

  tibble(
    Band.ID_1     = ids[pr[1, ]],
    Band.ID_2     = ids[pr[2, ]],
    JSD           = round(jsd_vals, 3),                          # "overall dissimilarity"
    jac_total     = round(as.numeric(jac$beta.jac),       3),
    jac_turnover  = round(as.numeric(jac$beta.jtu),        3),   # "different sites used"
    jac_nested    = round(as.numeric(jac$beta.jne),        3),   # "subset of sites"
    bray_total    = round(as.numeric(bray$beta.bray),      3),
    bray_balanced = round(as.numeric(bray$beta.bray.bal),  3),   # "uneven use of shared sites"
    bray_gradient = round(as.numeric(bray$beta.bray.gra),  3))
}

# Helper: long-format individual x site proportion matrix -> wide matrix
to_prop_matrix <- function(df) {
  wide <- df %>%
    select(Band.ID, recvDeployName, p) %>%
    pivot_wider(names_from = recvDeployName, values_from = p, values_fill = 0)
  m <- as.matrix(wide[, -1])
  rownames(m) <- wide$Band.ID
  m
}

# Results
divergence_global <- site_use_ind %>%
  group_by(speciesEN) %>%
  group_split() %>%
  map(function(df) {
    mat <- to_prop_matrix(df)
    res <- compute_divergence(mat)
    if (!is.null(res)) res$speciesEN <- df$speciesEN[1]
    res
  }) %>%
  compact() %>%
  bind_rows()

Jaccard & Bray-Curtis: dissimilarity decomposition

How much of their overall dissimilarity comes from not sharing sites (Jaccard turnover) versus sharing sites but using them unevenly (Bray-Curtis balanced variation)?

Tide and diel periods

We are now interested about the same question but depending the tide and diel. divergence_tide is the tide-specific version of divergence_global implementing the same pairwise metrics, but computed separately inside each tide category.

Birds are only compared if they were detected in the same tide category. A bird with no data in Nocturnal_Low is not in that tide’s pairs. Groups with fewer than 2 birds are skipped.

Statistical individual differences

Definition

PERMANOVA (vegan::adonis2, Anderson 2001) tests whether groups (here: individual birds) differ in the location (centroid) of their site-use composition, using a permutation test on the distance matrix itself rather than treating pairwise distances as independent samples (as would do Kruskal or ANOVA). Permutation test is distribution-free, robust to non-normal/compositional data, and is standard in ecology for kind of question.

For each species we use the four tideCategory per bird as replicate observations and test Bray-Curtis distance ~ Band.ID.

We pair this with PERMDISP (vegan::betadisper + permutest, Anderson 2006; Anderson & Walsh 2013) which tests whether individuals differ in dispersion (within-bird consistency) rather than in mean composition. This matters because PERMANOVA can be significant either because individuals truly use different site compositions, or because some individuals are simply more variable than others, and PERMDISP tells which one.

run_species_permanova <- function(sp_df, min_indiv = 3) {

  n_indiv <- n_distinct(sp_df$Band.ID)

  if (n_indiv < min_indiv) {
    return(tibble(n_indiv = n_indiv, n_obs = nrow(sp_df),
                  F = NA, R2 = NA, p_permanova = NA,
                  F_disp = NA, p_dispersion = NA,
                  note = paste0("Skipped: only ", n_indiv, " tagged individuals (need >= ", min_indiv, ")")))
  }

  # Build one row per Band.ID x tideCategory replicate profile (up to 4 rows per bird), site proportions in the columns:
  wide <- sp_df %>%
    mutate(row_id = paste(Band.ID, tideCategory, sep = "__")) %>%
    select(row_id, Band.ID, recvDeployName, p) %>%
    pivot_wider(names_from = recvDeployName, values_from = p, values_fill = 0)

  meta <- wide %>% select(row_id, Band.ID)
  mat  <- as.matrix(wide %>% select(-row_id, -Band.ID))
  rownames(mat) <- wide$row_id

  keep <- rowSums(mat) > 0     # drop empty replicate rows
  mat  <- mat[keep, , drop = FALSE]
  meta <- meta[keep, ]

  if (nrow(mat) < (n_indiv + 1)) {
    return(tibble(n_indiv = n_indiv, n_obs = nrow(mat),
                  F = NA, R2 = NA, p_permanova = NA,
                  F_disp = NA, p_dispersion = NA,
                  note = "Skipped: not enough replicate profiles per individual"))
  }

  d <- vegan::vegdist(mat, method = "bray")

  perm <- tryCatch(
    vegan::adonis2(d ~ Band.ID, data = meta, permutations = 999),
    error = function(e) NULL)

  disp <- tryCatch({
    bd <- vegan::betadisper(d, meta$Band.ID)
    vegan::permutest(bd, permutations = 999)
  }, error = function(e) NULL)

  tibble(
    n_indiv      = n_indiv,
    n_obs        = nrow(mat),
    F            = if (!is.null(perm)) round(perm$F[1], 2) else NA,
    R2           = if (!is.null(perm)) round(perm$R2[1], 3) else NA,
    p_permanova  = if (!is.null(perm)) perm$`Pr(>F)`[1] else NA,
    F_disp       = if (!is.null(disp)) round(disp$tab$F[1], 2) else NA,
    p_dispersion = if (!is.null(disp)) disp$tab$`Pr(>F)`[1] else NA,
    note         = "")
}
